# A.T.Field — Phase 1 (MVP) 테스트 가이드

이 문서는 Firefox에서 A.T.Field 확장을 실행하고 동작을 검증하기 위한 매뉴얼입니다.

---

## 1. 실행 방법

### 로컬 개발 모드로 실행
```bash
npm start
```
- Firefox 브라우저가 새 임시 프로필로 자동 실행되며 확장이 로드됩니다.
- 코드 변경 시 자동으로 리로드됩니다.

### 옵션 / 수동 로드 (`about:debugging`)
1. Firefox 주소창에 `about:debugging#/runtime/this-firefox` 입력
2. **임시 부가 기능 로드... (Load Temporary Add-on...)** 클릭
3. `at-field/manifest.json` 파일 선택

---

## 2. 테스트 체크리스트

### A. 기본 감지 및 프리셋 생성
- [ ] **비-YouTube 페이지**: Google, GitHub 등에서 팝업 열기 → "유튜브 동영상 재생 페이지가 아닙니다" 안내 표시
- [ ] **YouTube 홈 / 검색 결과**: `/watch`가 아닌 페이지에서 팝업 열기 → 안내 표시
- [ ] **동영상 재생 페이지 (`/watch`)**:
  - 팝업 열기 → 채널 이름이 정상적으로 표시되는지 확인
  - 프리셋이 없는 채널인 경우: `[+ 이 채널에 마스크 추가하기]` 버튼 표시
  - 버튼 클릭 시 기본 마스크가 영상 우하단(채팅창 위치)에 즉시 생성되고 자동으로 **편집 모드**로 진입

### B. 편집 모드 (Interactive Editor)
- [ ] **조작감**:
  - 마스크 본체 드래그로 이동
  - 8개 방향 핸들(모서리 및 상하좌우)로 크기 조절
  - 조작 중 YouTube 영상 재생/일시정지 또는 전체화면이 토글되지 않는지 확인 (`stopPropagation` 검증)
- [ ] **키보드 단축 조작**:
  - 화살표 키: 미세 1px 이동 (Shift + 화살표: 10px 이동)
  - `Esc` 키: 편집 취소 (편집 시작 전 위치로 롤백)
  - `Enter` 키: 저장 후 편집 모드 종료
- [ ] **보기 모드 전환**:
  - 팝업에서 "보기(View)" 버튼 클릭 시 편집 핸들과 테두리가 사라짐
  - 마스크 영역 위를 마우스로 클릭/드래그해도 영상 컨트롤 및 재생에 영향이 없는지 확인 (`pointer-events: none` 검증)

### C. 스타일 컨트롤
- [ ] **블러 (Blur)**:
  - 팝업에서 "블러" 선택 시 배경이 블러 처리(`backdrop-filter: blur()`)되고 반투명 색상 오버레이 적용
  - 블러 강도 슬라이더(0~40px) 실시간 반영 확인
- [ ] **단색 (Solid Color)**:
  - 팝업에서 "단색" 선택 시 블러가 꺼지고 불투명도 슬라이더에 따른 단색 배경 적용
  - 색상 피커로 색상 변경 시 실시간 반영 확인
- [ ] **불투명도 (Opacity)**:
  - 0% ~ 100% 슬라이더 조절 시 실시간 반영 확인

### D. 화면 전환 및 종횡비 (Aspect Ratio Tracking)
- [ ] **플레이어 모드 변경**: 기본 뷰 ↔ 극장 모드 ↔ 전체화면 전환 시 마스크가 영상 내 상대적 비율 위치를 정확히 유지하는지 확인
- [ ] **창 크기 조절**: 브라우저 창 크기를 조절할 때 부드럽게 재계산되는지 확인
- [ ] **레터박스 / 필러박스 보정**:
  - 4:3 비율 영상(좌우 블랙바) 및 21:9 시네마스코프 영상(상하 블랙바)에서 마스크 좌표가 블랙바를 제외한 실제 렌더링 영역 내에 고정되는지 확인

### E. 제외 대상 (Exclusion Rules)
- [ ] **광고 재생**: 광고가 나올 때 마스크가 자동으로 숨겨지고, 본편이 시작되면 다시 나타나는지 확인
- [ ] **미니플레이어**: YouTube 미니플레이어 활성화 시 마스크가 숨겨지는지 확인
- [ ] **Shorts**: `/shorts/...` 영상에서는 마스크가 동작하지 않는지 확인

### F. SPA 내비게이션 & 채널 분리
- [ ] **채널 A 영상 시청 중 마스크 설정**
- [ ] 우측 추천 영상 클릭하여 **채널 B 영상으로 이동**:
  - 채널 A의 마스크가 즉시 사라지는지 확인 (이전 마스크 잔상 방지)
  - 채널 B에 설정이 없다면 마스크가 뜨지 않고 팝업에 채널 B 이름이 표시되는지 확인
- [ ] 다시 뒤로가기로 **채널 A 영상으로 복귀**:
  - 채널 A의 마스크가 정상 복원되는지 확인

### G. 옵션 페이지 (전체 채널 관리)
- [ ] 팝업 하단의 "전체 채널 관리 ⚙️" 클릭 시 옵션 페이지가 새 탭으로 열림
- [ ] 저장된 채널 프리셋 카드 목록, 채널명, ID, 좌표(X/Y/W/H %), 스타일 정보 확인
- [ ] 채널 검색창에 이름 또는 ID 입력 시 실시간 필터링 확인
- [ ] "활성화(Active)" 체크박스 해제 시 해당 채널 마스크 즉각 비활성화
- [ ] "삭제(Delete)" 클릭 시 확인 후 프리셋 제거
- [ ] "기본 마스크 스타일" 변경 후 신규 채널에 마스크 추가 시 새 기본값이 적용되는지 확인

## 3. 개인 설치용 Unlisted 서명 (AMO Signing)

배포하지 않고 본인 Firefox에 영구 설치하기 위한 unlisted xpi 서명 방법:

1. [addons.mozilla.org](https://addons.mozilla.org/)에 접속하여 개발자 계정 생성
2. **도구 → API 키**에서 `JWT issuer (API Key)`와 `JWT secret (API Secret)` 발급
3. 루트 디렉터리에 `.env` 파일 생성 (gitignore에 등록되어 있음):
   ```env
   WEB_EXT_API_KEY=user:xxxx:xxx
   WEB_EXT_API_SECRET=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
4. 서명 명령 실행:
   ```bash
   npm run sign
   ```
5. `web-ext-artifacts/` 디렉터리에 생성된 서명된 `.xpi` 파일을 Firefox 브라우저로 드래그 앤 드롭하여 영구 설치
